# 🪨📄✂️ JokenPô

Jogo de **Pedra, Papel e Tesoura** desenvolvido com HTML, CSS e JavaScript puro. O jogador escolhe sua jogada clicando em um dos botões e disputa contra a máquina, que escolhe aleatoriamente.

---

## 🎮 Como Jogar

1. Abra o arquivo `index.html` no navegador.
2. Clique em uma das opções: **Pedra (rock)**, **Papel (paper)** ou **Tesoura (scissors)**.
3. A máquina faz sua escolha automaticamente.
4. O resultado aparece na tela junto com a atualização do placar.

### Regras
- 🪨 Pedra vence Tesoura
- 📄 Papel vence Pedra
- ✂️ Tesoura vence Papel
- Mesma escolha = Empate

## ⚙️ Funcionalidades

- ✅ Escolha aleatória da máquina
- ✅ Exibição do resultado (vitória, derrota ou empate)
- ✅ Placar acumulado do jogador e da máquina
- ✅ Cores dinâmicas no resultado (verde = vitória, vermelho = derrota, azul = empate)
- ✅ Animação nos botões ao passar o mouse (hover) e ao clicar (active)
- ✅ Layout responsivo para dispositivos móveis

---

## 📱 Responsividade

O projeto adapta o fundo para telas menores que **768px**, exibindo uma imagem otimizada para formato vertical (9:16).

---

## 🚀 Como Executar

Não é necessário nenhuma instalação. Basta:

```bash

start index.html
```

Ou abra o arquivo `index.html` diretamente no seu navegador preferido.
